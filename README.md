# Kallr

**Pronunciation:** /ˈkɑːlər/ (KAHL-er)

A cross-platform local notification service.

## Development

Requires pnpm and the Dart SDK (`^3.14.0`).

| Command                  | Purpose                                           |
| ------------------------ | ------------------------------------------------- |
| `pnpm run test:dart`     | Run the Dart tests of `poc/windows/w1-w7-verify`  |
| `pnpm run check:dart`    | Check Dart formatting (`apps`, `packages`, `poc`) |
| `pnpm run lint:markdown` | Lint Markdown documents                           |

`poc/` holds proof-of-concept code; each PoC has its own `package.json` for its scripts.
